# Public download page

`index.html` is the source for <https://venes.org/fjoscam/>. It reads the generated Windows and macOS updater feeds and links to the corresponding release installers.

After verifying a release, copy this HTML into the approved Fjoscam public staging directory. Keep the existing `fjoscam01.png` screenshot and historical release artifacts there. Follow the publication procedure in `RELEASING.md` and the active operator instructions; committing this file does not publish the website.

Update the visible release notes and installation information together with each new release. Do not hand-edit generated feed hashes or include private configuration in the website.
