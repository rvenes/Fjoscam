Why Fjoscam?

Fjoscam started after using the Reolink app for sheep monitoring during lambing season. In that situation, you want to move the camera, switch views and jump to saved positions without opening several menus first.

Fjoscam keeps the most useful controls directly available from the keyboard and the main window.

What’s new in Fjoscam 1.0.8

Released 22 September 2026. This release improves connection security, video recovery and everyday camera controls on Windows, Mac Apple Silicon and Mac Intel.

  • Safer saved credentials
    Generic RTSP/RTSPS stream URLs are now encrypted with the operating system, alongside camera passwords. Existing valid configuration and backup files are migrated automatically.
  • Verified camera certificates
    HTTPS camera connections and generic RTSPS streams now verify certificates. Self-signed cameras have an explicit fingerprint inspection and confirmation workflow.
  • Automatic video recovery
    If the local video service crashes, Fjoscam makes a limited number of restart attempts and restores the active stream. Your selected High/Clear quality is preserved.
  • More reliable camera controls
    Improved Reolink authentication, capability detection, zoom and ONVIF movement/Stop handling when cameras are slow or offline.
  • Clearer diagnostics
    Camera search shows its network coverage and limits. Playback, updates and recovered camera settings have clearer status messages.
  • Smoother daily use
    More consistent fullscreen and dialog keyboard controls, less repeated camera polling, and better cleanup when switching cameras or closing the app.
  • Refreshed platform builds
    Updated dependencies and smaller bundled video components, with automated app, encrypted-connection and playback checks on all three platform targets.

Before updating

  • Self-signed HTTPS/RTSPS cameras may need a one-time certificate confirmation. Independently verify the fingerprint before accepting it.
  • ONVIF PTZ fallback is now an explicit per-camera opt-in, with a separate HTTP port. Reolink API controls remain the primary path.
  • Camera names, hosts and usernames are still ordinary local configuration. Encryption is tied to your OS account; older external backups are not changed.
  • Older Fjoscam versions cannot read the new encrypted generic-stream URLs. Avoid editing migrated camera data with an older version.

Key features

  • Easy PTZ control
    Move cameras with buttons, video click/hold, arrow keys, WASD or numpad.
  • Direct presets
    Recall PTZ presets with number keys, and save or delete Reolink presets from the app.
  • Fast camera switching
    Use PgUp and PgDn to move between cameras.
  • Fullscreen control
    Press Enter or F11 for fullscreen. Keyboard controls still work.
  • Audio support
    Reolink and UniFi/generic RTSP audio works, with volume and mute controls.
  • Local setup
    Camera configuration is stored locally. Passwords and generic stream URLs are encrypted with Electron safeStorage.
  • Windows and macOS
    Downloads are available for Windows, Mac Apple Silicon and Mac Intel.

Supported camera types

Reolink LAN cameras

  • Tested with RLC-523WA, RLC-823A and TrackMix WiFi.
  • Uses Reolink HTTP API for login, PTZ, presets, zoom, focus, lights and siren where supported.
  • Uses RTSP through go2rtc for video.
  • Reolink video and audio works through the MSE-based go2rtc player.

UniFi Protect / generic RTSP

  • Tested with UniFi Protect RTSP/RTSPS shared links.
  • Video and audio works through go2rtc/WebRTC/RTC.
  • No PTZ or presets for generic streams.

Panasonic legacy MJPEG

  • Tested with an older Panasonic MJPEG camera.
  • Supports MJPEG video and Panasonic CGI pan/tilt/zoom/focus/presets.
  • No audio.

Keyboard shortcuts

  • Enter / Numpad Enter / F11: fullscreen
  • Esc: exit fullscreen
  • PgUp / PgDn: switch camera
  • WASD, arrow keys or numpad: PTZ movement
  • Numpad 5: stop PTZ movement
  • Numpad + / Numpad -: PTZ speed
  • Numpad * / Numpad /: optical zoom in/out
  • Numpad .: mute/unmute active stream
  • 1 to 9: go to PTZ preset
  • F1: open tips

Streaming and audio

  • MSE: used for Reolink video and audio when it gives the best result.
  • RTC/WebRTC: used especially for UniFi and generic RTSP/RTSPS streams.
  • MJPEG: used for legacy Panasonic cameras.
  • Volume slider and mute/unmute work per active stream.
  • Audio errors should not stop video playback.

Camera management

  • Add, edit and delete cameras.
  • Reolink LAN discovery / subnet scan.
  • Already added cameras are marked in the discovery list.
  • Edit mode keeps the normal UI cleaner.
  • Responsive add camera dialog for smaller windows.

Connection and privacy

Fjoscam is built for local use. Use it on your LAN, or through a trusted VPN such as Tailscale for remote access. Reolink UID/P2P access is not supported.

  • Camera setup is stored locally on the PC.
  • Passwords and generic stream URLs are encrypted with Electron safeStorage.
  • go2rtc and the snapshot server are intended to run locally.
  • External links are limited to known HTTPS domains.
  • Logs try to mask sensitive tokens, credentials and query values.

Updates and source code

Fjoscam uses a Windows NSIS installer and macOS builds. The update feed is hosted at venes.org/fjoscam. Release files include latest.yml, latest-mac.yml, installers/archives and matching .blockmap files.

The source code is available on GitHub and released under the MIT license.

What Fjoscam does not do yet

Playback of recordings stored on the camera is not implemented yet. For camera recordings, firmware updates, UID/P2P access and some advanced camera settings, the official camera apps may still be needed.

Fjoscam is an independent open source project. It is not an official Reolink, UniFi or Panasonic app.
